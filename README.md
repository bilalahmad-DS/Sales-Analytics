# Sales Analytics & Business Performance Analysis

## Project Overview

This project analyzes sales transaction data to understand business
performance and identify important sales trends and patterns.

## Business Problem

The goal is to identify top-performing products, categories, cities,
and months and provide data-driven business recommendations.

## Dataset

- 1,010 original transactions
- 995 transactions after cleaning
- 9 columns

## Tools

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning

- Handled missing values
- Removed duplicate records
- Investigated revenue outliers
- Retained legitimate high-value transactions

## Key Analysis

- Revenue by product
- Revenue by category
- Revenue by city
- Monthly revenue trends
- Top customers
- Quantity vs. revenue relationship
- Key performance indicators (KPIs)

## Key Findings

- Electronics was the top revenue-generating category.
- Laptop was the top revenue-generating product.
- Abbottabad was the top revenue-generating city.
- May was the strongest month.
- Quantity and revenue showed a moderate positive relationship.

## Business Recommendations

- Focus on high-revenue products such as Laptops.
- Strengthen the Electronics category.
- Investigate high-performing cities.
- Analyze the factors behind strong monthly performance.

## Project Structure

- `Sales_Analytics_Business_Performance.ipynb` — complete analysis
- `sales_data.csv` — dataset
- `README.md` — project documentation

## Conclusion

This project demonstrates how Python and data analysis can transform
raw sales data into useful business insights and recommendations.
